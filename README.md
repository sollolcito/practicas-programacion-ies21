# Conversor de temperaturas

Aplicación de escritorio para convertir temperaturas entre **Celsius, Fahrenheit y Kelvin**, desarrollada como práctica de programación en IES21.

**Tecnologías:** C# · Windows Forms · .NET Framework 4.7.2

## Probar la aplicación

Dentro de la carpeta **VerificacionFrameworkCompilado** encontrarás:

- **LEEMEVerificarNetFrame.md:** instrucciones para comprobar si tu equipo cumple el requisito de .NET Framework.
- **Archivo RAR:** versión compilada de la aplicación.

Primero consultá la guía. Después descargá el RAR, extraé todo su contenido y ejecutá el archivo `.exe`, manteniendo juntos los archivos incluidos. **No necesitás Visual Studio.**

## Revisar el código

Abrí `ClaseEquivalenciasTemperatura.csproj` en Visual Studio con las herramientas de desarrollo de escritorio de .NET y los componentes de destino de **.NET Framework 4.7.2**. Luego compilá y ejecutá el proyecto.

Las carpetas `bin` y `obj` se generan al compilar y no se incluyen en el código fuente.
