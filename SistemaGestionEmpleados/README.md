# Sistema de Gestión de Empleados — IES21

Trabajo práctico de **Laboratorio de Programación 1**, desarrollado en **C# Windows Forms**, Visual Studio 2017 y .NET Framework 4.7.2.

## Ejecutar (sin Visual Studio)

1. Descargá y extraé el proyecto.
2. Dentro del proyecto extraído, abrí `SistemaGestionEmpleados/bin/Debug/`.
3. Hacé doble clic en **`SistemaGestionEmpleados.exe`**.

Ruta desde la raíz del proyecto extraído: `SistemaGestionEmpleados/bin/Debug/SistemaGestionEmpleados.exe`.

Necesitás Windows y **.NET Framework 4.7.2**. Conservá el archivo `.exe.config` junto al ejecutable. Si no encontrás la carpeta `bin/Debug`, compilá el proyecto desde Visual Studio como se indica abajo.

## Abrir el código y compilar

Abrí `SistemaGestionEmpleados.sln` en Visual Studio 2017 (o una versión compatible). Presioná **F5** para ejecutar, o **Ctrl + Shift + B** para compilar; se generará/actualizará el ejecutable en `SistemaGestionEmpleados/bin/Debug/`.

## Funcionalidad

Altas, consultas, búsquedas y listados de empleados por diferentes criterios. Incluye el formulario «Acerca de…».

Los datos se manejan en memoria: ejercicio académico.
