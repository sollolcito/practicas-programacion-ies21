# SistemaGestionClientes

Práctica de C# y Windows Forms desarrollada para IES21.

## Requisitos

- Visual Studio Community 2017 (15.8 o posterior) con Desarrollo de escritorio de .NET.
- .NET Framework 4.7.2 y su paquete de desarrollo.

## Abrir el proyecto

Abrí `SistemaGestionClientes.sln` con Visual Studio 2017, compilá y ejecutá con F5.

## Estructura

La solución incluye siete formularios de Windows Forms y la clase `Vector.cs` con datos compartidos.

Los archivos `.Designer.cs` y `.resx` forman parte del diseño de los formularios. No se incluyen carpetas `bin` ni `obj` porque se generan al compilar.
