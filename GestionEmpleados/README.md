# Gestión de Empleados

**IES21 — Laboratorio de Programación 1**  
**Actividad de repaso: Vectores y Registros**

## Objetivo

Desarrollar en C# con Windows Forms un sistema para administrar hasta 100 empleados, aplicando registros, vectores, procedimientos y estructuras secuenciales, alternativas y repetitivas.

## Datos de cada empleado

- Código: `int`
- Nombre: `string`
- Categoría: `int`
- Sueldo: `decimal`

Los datos se almacenarán en un vector de registros compartido entre los formularios, con un índice global para la carga.

## Funciones solicitadas

- Menú **Sistema**: Acerca de y Salir.
- Menú **Empleado**: agregar, listar todos, listar por categoría, listar por sueldo superior a un importe, consultar por nombre y buscar por código.
- Listados con `DataGridView`, cantidad de empleados y total de sueldos.
